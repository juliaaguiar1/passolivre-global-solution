# Checklist de entrega e testes - PassoLivre

## 1. Antes de entregar
- [ ] Preencher no PDF nome completo e RM de **todos os integrantes em ordem alfabética**.
- [ ] Confirmar que o grupo tem de 2 a 5 pessoas.
- [ ] Instalar dependências, iniciar o Expo e testar em um celular real.
- [ ] Publicar o código e README em repositório **público**.
- [ ] Substituir no PDF e README os marcadores por URL real do GitHub.
- [ ] Gravar vídeo mostrando a jornada, motion e acessibilidade, com 2 a 3 minutos.
- [ ] Publicar o vídeo e colocar URL real no PDF e README.
- [ ] Enviar o PDF atualizado pela plataforma.

## 2. Cenários de testes obrigatórios para a equipe executar
- [ ] Navegar em Início > Explorar > Registros > Ajustes sem erros.
- [ ] Criar um registro e verificar tela de confirmação.
- [ ] Reiniciar o app e verificar se o registro permanece no histórico.
- [ ] Ativar o modo avião *depois de iniciar o app* e criar outro registro.
- [ ] Testar formulário vazio, título curto, endereço curto, descrição curta.
- [ ] Recusar acesso à localização e completar preenchimento manual.
- [ ] Recusar acesso à galeria e salvar sem imagem.
- [ ] Adicionar foto e conferir prévia e detalhes (se permissão concedida).
- [ ] Filtrar as categorias em Explorar.
- [ ] Excluir registro com confirmação.
- [ ] Verificar fontes grandes, alto contraste e redução de movimento.
- [ ] Navegar com TalkBack ou VoiceOver, incluindo formulário.
- [ ] Verificar legibilidade com fonte do sistema ampliada.

## 3. Avaliação crítica: oportunidades para nota maior
- [ ] Documentar uma observação ou entrevista real, com consentimento (nunca inventar falas).
- [ ] Adicionar evidências reais dos testes, prints do app e melhorias feitas após os testes.
- [ ] Justificar que inovar não exige declarar integração governamental inexistente.
- [ ] Garantir vídeo claro, com demonstração real e sem promessas técnicas não implementadas.
